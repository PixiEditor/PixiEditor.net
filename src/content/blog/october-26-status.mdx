## Text Rework

This is a pretty big thing, I'll be honest, I underestimated the amount of work of this thing.
The original idea was to just add **text alignment** options, as this was often mentioned as missing. 
I thought "eh, if I am touching text, I might as well improve it a bit more".

Right now, if you want to have a text with different colors, fonts or any other settings, you need a separate 
layer for each. It's far from being ideal and requires a lot of patience to get right.

It should work like in text processors, where you select a part of the text and just change the settings for 
a selection. And this is what I decided to do.

[[video]]

Boy oh boy, this was quite a rabbit hole, it required to adjust everything related to text. Editing, rendering,
svg export and import, overlays, converting to curve, shape data recoloring, extracting characters and much more.

It took me about 3 weeks if not more.

Well, not only this, in the meantime I also decided to add mentioned text alignment and various other settings 
like proper font styles and new font picker UI.

## Token beam

In the meantime of the meantime I wanted to play around token beam (TODO LINK). It's a fun technology
made by meodai (add name?), a very talented programmer focused on color theory and colors in general.

Its purpose is to connect external color pickers/palette generators with target graphics software. So 
for example I can use [this website] to pick my colors for a palette and see it immediately update in PixiEditor.

[[video]]

An experimental extension is available now (push and put a link there). It is only working with dev version as of today
(version >=2.2), so you might need to update to see it in the extension library.

Let me know what you think!
