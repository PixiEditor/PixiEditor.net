## Current focus - Project polish

As described in [the previous blog post](/blog/2026/09/04/september-26-status), we're currently working
on polishing PixiEditor and adding missing essential features.

Axin has recently performed some user tests, which helped us understand what is not intuitive, missing, or simply
confusing. We've combined these tests, feedback from the forum, Discord, and reviews on Steam and prepared 
a matrix of things we want to handle.

to version 2.1 and some will wait for the 2.2 release.

## Text Rework

This is a pretty big thing. I'll be honest, I underestimated the amount of work of this thing.
The original idea was to just add **text alignment** options, as this was often mentioned as missing. 
I thought, "eh, if I am touching text, I might as well improve it a bit more".

Right now, if you want to have text with different colors, fonts, or any other settings, you need a separate 
layer for each. It's far from being ideal and requires a lot of patience to get right.

It should work like in text processors, where you select a part of the text and just change the settings for 
a selection. And this is what I decided to do.

<video src='/videos/october-26-status/TextRework.webm' loop autoplay muted controls playsinline/>

Boy oh boy, this was quite a rabbit hole. It required adjusting everything related to text. Editing, rendering,
SVG export and import, overlays, converting to curves, shape data recoloring, extracting characters, and much more.

It took me about 3 weeks, if not more.

Well, not only this, but in the meantime I also decided to add the mentioned text alignment and various other settings 
like proper font styles and a new font picker UI.

## Token Beam

In the meantime of the meantime, I wanted to play around with the [token beam](https://tokenbeam.dev/). It's a fun technology
made by [David Aerne (meodai)](https://github.com/meodai), a very talented programmer focused on color theory and colors in general. 
Shoutout to him for great work.

Its purpose is to connect external color pickers/palette generators with target graphics software. So 
for example, I can use [this website](https://farbvelo.elastiq.ch) to pick my colors for a palette and see it immediately update in PixiEditor.

<video src='/videos/october-26-status/tokenbeam.webm' loop autoplay muted controls playsinline/>

An experimental extension is [available now](https://pixieditor.net/extensions/PixiEditor.TokenBeam/). It is only working with the dev version as of today.
(version >=2.2), so you might need to update to be able to install it.

Let me know what you think!
