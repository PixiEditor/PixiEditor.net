PixiEditor is an open-source app. It was built to be an open-source app, and everything it stands behind is based on being open source.

Though it's not just a fun hobby project anymore, it needs funding.

A lot of open source apps base their funding on sponsors and donations. This works well for some of them. However, we want to be more independent and not rely on the goodwill of others. We want to be able to plan the development and not worry about whether we will have enough money to pay for the next month of work.

We want to be clear and open about how we're going to do this.

## The app itself

First and foremost, **the base open source PixiEditor app is free, and will be**. We do not plan to chop its features and sell them either.

## Extensions

In version 2.1, we have introduced an extension browser with free and paid extensions, such as pre-built workspaces, brushes, palettes and tools. Most of the items you are able to buy there 
are something that you would be able to make yourself. In other words, we are creating things using PixiEditor's core systems that everyone has equal access to.

This way, we can share useful setups and tools, and you can support the development. It's a win-win. 

The extension browser primarily works in an ownership model. So buy once, and it's yours.
